# PRD - Todo App

## 목표
- 혼자 쓰는 간단한 할 일 목록 웹 앱을 만들어, 사용자가 할 일을 빠르게 기록하고 완료 여부를 관리할 수 있게 한다.
- 로그인/계정 없이 바로 쓸 수 있는 개인용 도구를 지향한다.
- (부가 목표) AI 풀스택 과정 2차 프로젝트 준비를 위한 학습용 프로젝트로 FastAPI·React·PostgreSQL 스택을 단계적으로 익힌다.

## 대상 사용자
- 혼자 할 일을 관리하고 싶은 개인 사용자 1명 (계정/로그인 없음, 다중 사용자 미지원)
- 복잡한 일정 관리 도구보다 가볍고 빠른 입력을 원하는 사용자

## 기능 목록

| ID | 기능 | 설명 |
|---|---|---|
| F-01 | 할 일 추가 | 제목을 입력해 새 할 일을 등록한다. 제목은 필수이며 1~100자 |
| F-02 | 할 일 목록 보기 | 등록된 할 일을 최신순으로 목록에 표시한다 |
| F-03 | 완료/미완료 전환 | 체크박스로 할 일의 완료 상태를 전환한다 |
| F-04 | 할 일 삭제 | 더 이상 필요 없는 할 일을 목록에서 삭제한다 |
| F-05 | 데이터 유지 | 새로고침해도 등록한 할 일 데이터가 유지된다 |

## 사용자 스토리
- 사용자로서, 떠오른 할 일을 빠르게 기록하고 싶다. 그래야 잊어버리지 않는다. (F-01)
- 사용자로서, 등록한 할 일을 최신순으로 한눈에 보고 싶다. 그래야 지금 해야 할 일을 바로 파악할 수 있다. (F-02)
- 사용자로서, 완료한 항목을 체크하고 싶다. 그래야 진행 상황을 추적할 수 있다. (F-03)
- 사용자로서, 더 이상 필요 없는 항목을 지우고 싶다. 그래야 목록을 깔끔하게 유지할 수 있다. (F-04)
- 사용자로서, 새로고침하거나 다시 접속해도 입력한 내용이 남아있길 원한다. 그래야 데이터를 잃어버릴 걱정 없이 쓸 수 있다. (F-05)

## 범위 밖
- 로그인/회원가입, 다중 사용자 지원
- 할 일 공유 (다른 사람과 목록 공유)
- 알림/리마인더
- 마감일 설정
- 카테고리/태그 분류
- 할 일 수정, 필터링은 현재 범위 밖이며 이후 버전(v0.4)에서 다룬다 (docs/IDEA.md 로드맵 참고)

## 성공 기준
- 제목 없이(빈 값) 또는 100자를 초과해 등록을 시도하면 등록이 거부되고 사용자에게 안내된다
- 할 일을 등록하면 목록 맨 위(최신순)에 즉시 나타난다
- 체크박스를 클릭하면 완료/미완료 상태가 즉시 반영된다
- 삭제한 항목은 목록에서 즉시 사라지고 다시 나타나지 않는다
- 브라우저를 새로고침하거나 다시 접속해도 추가·완료·삭제 상태가 그대로 유지된다
