# 무료 배포 가능한 초보자용 스택 3안

| | A. FastAPI + React + Postgres | B. Next.js 풀스택 (Vercel) | C. 정적 React + localStorage |
|---|---|---|---|
| 백엔드 | FastAPI (Render/Railway 무료 티어) | Next.js API Routes (Vercel 자체 호스팅) | 없음 |
| DB | PostgreSQL (Neon/Supabase 무료) | PostgreSQL (Neon/Vercel Postgres) | 없음 (브라우저 저장) |
| 배포 난이도 | 백엔드/프론트/DB 3곳 따로 설정 — CORS, 환경변수 연결 필요 | 레포 하나를 Vercel에 연결하면 끝, 가장 쉬움 | git push만 하면 끝, 제일 쉬움 |
| 비용 | 전부 무료 티어로 가능하지만 백엔드(Render)는 비활성 시 슬립 → 첫 요청 콜드스타트 수십 초 | 개인 사용 수준에서 완전 무료, 콜드스타트 체감 적음 | 완전 무료, 콜드스타트 없음 |
| 커리큘럼 연계 | FastAPI/SQLAlchemy/Alembic을 그대로 연습 → 2차 프로젝트로 직결 | TypeScript/Next.js App Router 등 커리큘럼에 없는 개념 추가 학습 필요 | 서버/DB 개념 연습 자체가 없음 |
| 데이터 지속성 | 서버 DB — 다른 기기에서도 접근 가능 | 서버 DB — 동일 | 브라우저 로컬에만 저장, 기기 바뀌면 사라짐 |

## 추천
A안. 지금 CLAUDE.md에 맞춰둔 FastAPI+React+Postgres 그대로 가는 게 맞다. 2차 프로젝트 커리큘럼(FastAPI/SQLAlchemy/Alembic)과 배우는 내용이 완전히 겹쳐서, 배포 설정이 조금 번거로운 대신 학습 전이 효과가 가장 크다. 무료 조합 예시: 백엔드 Render(또는 Railway), DB Neon, 프론트 Vercel/Netlify.

다만 지금 로드맵(v0.1 화면만)에서는 아직 배포할 게 없으니, v0.1~v0.2 단계는 로컬에서만 돌리고, v0.3(DB 연결) 끝난 뒤 한 번에 배포 설정을 익히는 게 단계별 학습 순서상 자연스럽다. C안은 "일단 뭐라도 배포해보고 싶다"는 조기 성취감용으로만 참고.
