# TRD - Todo App

## 개요
docs/PRD.md의 기능(F-01~F-05)을 CLAUDE.md에 정의된 스택(FastAPI + React + PostgreSQL)으로 구현하기 위한 기술 설계 문서. 이 스택은 AI 풀스택 과정 커리큘럼(FastAPI/SQLAlchemy/Alembic)과 그대로 맞춰 선택했다.

## 기술 스택과 선택 이유

| 기술 | 역할 | 왜 골랐나 (초보자 기준) |
|---|---|---|
| Python + FastAPI | 백엔드 서버 | 파이썬은 문법이 간단해 처음 배우기 쉽고, FastAPI는 타입(자료형)만 적어도 요청 값 검증과 API 문서를 자동으로 만들어준다 |
| React (Vite, JavaScript) | 프론트엔드 화면 | 화면을 버튼·목록 같은 작은 "컴포넌트" 단위로 쪼개서 만들 수 있어 복잡한 화면도 나눠서 이해하기 쉽고, Vite는 코드를 저장하면 바로 화면에 반영돼 결과를 빠르게 확인할 수 있다 |
| Tailwind CSS | 화면 스타일링 | 정해진 클래스 이름을 붙이기만 하면 스타일이 적용돼서, CSS 문법을 깊이 몰라도 화면을 빠르게 꾸밀 수 있다 |
| PostgreSQL | 데이터 저장소(DB) | 무료로 쓸 수 있고 실무에서도 널리 쓰이는 안정적인 DB라서, 여기서 배운 내용이 그대로 실무/2차 프로젝트에 쓰인다 |
| SQLAlchemy | ORM (DB 접근 도구) | SQL 문장을 직접 안 쓰고 파이썬 코드(클래스, 함수)로 DB 테이블을 다룰 수 있게 해줘서 초보자가 SQL과 파이썬 양쪽을 한 번에 배우지 않아도 된다 |
| Alembic | DB 마이그레이션 관리 | 테이블 구조(예: 컬럼 추가)가 바뀔 때 변경 이력을 자동으로 기록·적용해줘서, 수동으로 DB를 고치다 실수하는 걸 막아준다 |
| Pydantic | 요청 데이터 검증 | FastAPI에 내장돼 있어 별도 설치 없이, "제목은 1~100자" 같은 규칙을 타입 선언만으로 자동 검사해준다 |
| Swagger (FastAPI 자동 문서화) | API 문서 | 코드만 작성하면 API 사용법 문서가 자동 생성되고 브라우저에서 바로 테스트해볼 수 있어, API 명세서를 따로 찾아볼 필요가 줄어든다 |
| pytest | 테스트 | 파이썬에서 가장 널리 쓰이는 테스트 도구라서, 기능이 의도대로 동작하는지 코드로 확인하는 습관을 쉽게 들일 수 있다 |

## 전체 구조

```
[브라우저]
   React (화면, 버튼 클릭 처리)
        |  HTTP 요청 (JSON)
        v
[백엔드 서버]
   FastAPI (요청 접수) -> Pydantic (값 검증) -> SQLAlchemy (DB 명령 생성)
        |
        v
[DB]
   PostgreSQL (실제 저장)
```

## 흐름: "할 일 추가" 버튼을 누른 뒤 DB에 저장되기까지 (F-01 기준)

1. 사용자가 입력창에 할 일 제목을 입력하고 **추가 버튼을 클릭**한다.
2. React가 버튼 클릭 이벤트를 감지하고, 입력창에 담긴 텍스트를 가져온다.
3. React가 이 텍스트를 JSON으로 담아 FastAPI 서버에 **POST 요청**을 보낸다. (예: `POST /todos`, `{ "title": "우유 사기" }`)
4. FastAPI가 요청을 받으면, 가장 먼저 **Pydantic**이 요청 값을 검사한다. (제목이 비어 있거나 100자를 넘으면 여기서 막히고 오류 응답을 바로 돌려준다 — PRD 성공 기준과 연결)
5. 검증을 통과하면 FastAPI 라우터가 해당 요청을 처리하는 함수(서비스/CRUD 계층)로 넘긴다.
6. 그 함수가 **SQLAlchemy**로 "할 일" 객체를 만들고, DB에 저장하라는 명령(SQL의 INSERT에 해당)을 생성한다.
7. SQLAlchemy가 **PostgreSQL**에 실제로 데이터를 저장(INSERT)하고 커밋한다.
8. 저장이 끝나면 DB가 새로 생성된 항목의 id와 생성 시각 등을 돌려준다.
9. FastAPI가 저장된 할 일 정보를 JSON 응답으로 React에 돌려준다. (예: `{ "id": 1, "title": "우유 사기", "done": false }`)
10. React가 응답을 받아 화면의 할 일 목록 상태(state)에 새 항목을 추가하고, 화면에 **최신순으로 즉시 표시**한다.

## 버전별 적용 범위
- v0.1 (화면만): 위 흐름 중 1~2, 10단계만 해당. 서버/DB 없이 React 상태에만 저장
- v0.2 (API 연결): 1~10단계와 비슷하지만 7~8단계의 "DB 저장"이 서버 메모리 저장으로 대체됨
- v0.3 (DB 저장)부터: 위 흐름 1~10단계가 전부 그대로 적용됨
